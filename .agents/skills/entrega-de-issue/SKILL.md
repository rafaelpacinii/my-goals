# Entrega de issue

1. Leia a issue, suas dependências, o [planejamento](../../../docs/07-planejamento-github.md)
   e os requisitos, histórias e diagramas que ela cita. Confira o que já existe no código.
2. Escreva ou detalhe a menor entrega verificável que cobre o objetivo. Indique RF/UC,
   critérios observáveis, dependências e milestone. Use [TASK.md](../../../TASK.md)
   para decompor o trabalho em execução e registrar decisões e evidências.
3. Escolha as skills específicas do módulo. Atualize os documentos afetados pelo
   comportamento e verifique os caminhos de aceite e regressões pertinentes.
4. Apresente a conclusão com a skill [git-entrega](../git-entrega/SKILL.md).
   Vincule a issue no PR com `Closes #N` quando todos os seus critérios forem satisfeitos.
